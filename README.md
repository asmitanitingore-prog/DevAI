\# 🤖 DevAI



DevAI is a Python-based developer productivity toolkit built with Streamlit.



It provides multiple developer-focused analysis tools through a single web interface.



\## 🚀 Features



\### 🔍 Code Reviewer

\- Python syntax validation

\- Code quality scoring

\- Cyclomatic complexity analysis

\- Maintainability analysis

\- Function and class detection

\- Security issue detection

\- Code improvement suggestions



\### 🐞 Bug Analyzer

\- Python error detection

\- Error type identification

\- Likely cause analysis

\- Suggested fixes for common Python errors



\### 📄 Resume Intelligence

\- PDF resume text extraction

\- Technical skill detection

\- Job description matching

\- TF-IDF based similarity scoring

\- Matching skill identification

\- Missing skill identification



\## 🛠️ Technologies



\- Python

\- Streamlit

\- Pandas

\- NumPy

\- Scikit-learn

\- PyMuPDF

\- Radon

\- Python AST
